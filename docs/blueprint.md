# **App Name**: CustoCerto

## Core Features:

- Dashboard: Dashboard Principal with graphs, CMV control and goal spending tracker.
- Purchase Entry: Interface for registering merchandise entries, including supplier selection and item details.
- Ingredient List: Display and manage a list of ingredients with current costs and units.
- Recipe Management: Create and edit recipe datasheets, calculating production costs and product CMV in real time.
- Reporting: Generate various reports including most purchased ingredients, cost analysis, purchase quantities, and ABC curve analysis based on selected period.

## Style Guidelines:

- Primary color: Deep Emerald (#50C878) to convey financial stability and growth, in line with the app's cost-saving focus.
- Background color: Soft Mint (#E0F8E0), providing a clean, calming backdrop that enhances readability and focus.
- Accent color: Golden Yellow (#FFD700) to highlight key metrics, actionable items, and important alerts within the interface.
- Body and headline font: 'Inter' (sans-serif) for clear, modern readability across all sections of the app.
- Use clean and consistent icons related to ingredients, purchases, and reports to aid navigation.
- Implement a clear and structured layout with intuitive navigation.
- Subtle animations on data updates to improve user engagement
